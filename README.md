# Tic Tac Hell ☠️ (Java Edition)

A sarcastic, deliberately unfair Java Swing tic-tac-toe game. The board starts at 3×3 and never exceeds 10×10.

## Run
Requires Java 11 or newer.

```bash
javac -d out src/TicTacHell.java
java -cp out TicTacHell
```

## Features
- Interactive board and cheating AI
- Board mutations capped at 10×10
- Fake operating-system alerts contained inside the game
- Corrupt courtroom and fictional terminal
- Five hidden clues and two secret endings

## Secret ending
Reach 10×10, collect five clues, expose the judge in court, then enter `who_makes_the_rules` in the terminal.

The application does not access real operating-system settings or run terminal commands.
